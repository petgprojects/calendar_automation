Safety and recovery

Close Word before updating. Use only one computer for this folder. Keep the hidden .calendar-import folder with your documents: it contains backups and duplicate-prevention history.

What can be imported?

Full names or first-name/last-initial names (e.g. MandyT) followed by :- start each note. Blank lines stay within notes. Filenames may use either form and must include Student or Teacher Progress Note and the school year. The internal Word name must match. Existing two-column date/comments forms are required.

Embedded PNG/JPEG images in an HTML calendar description are supported. Links, missing attachments and unsupported layouts are held for review; no image is fetched from the internet. A file cannot supply content Outlook omitted. The supplied screenshot placeholders are text, not real images.

Changed notes update automatically only when a newer source revision can be established and the linked Word entry is unchanged. Missing events never delete Word entries. This unsigned first release needs recipient testing before use with live records.

Private by design. Notes, backups and settings stay on this computer. No accounts or network connection required.
